# Development

Everything here builds with tools already present on Windows 10/11. No SDK, package manager or NuGet.

## Layout

```text
Glance.ps1                 The application: metrics worker + WPF overlay + settings window (single file)
Start-Glance.vbs           Runs Glance.ps1 with no console window (script mode)
Build.ps1                  Builds dist\Glance.exe, dist\Glance-Setup.exe, dist\Glance-Setup.cmd
src\Host.cs                Native host: embeds Glance.ps1 and runs it in-process in Windows PowerShell 5.1
src\Glance.manifest        asInvoker + DPI-aware manifest for Glance.exe
installer\Install.ps1      Installer logic (shared by both setup flavours)
installer\Uninstall.cmd    Uninstaller (self-deleting)
installer\SetupStub.cs     Glance-Setup.exe: extracts embedded files to %TEMP% and runs Install.ps1
installer\SetupStub.manifest
docs\screenshots\          Generated by the headless run (see below)
dist\                      Build output (committed so releases can be downloaded directly)
```

## Build

```powershell
powershell -ExecutionPolicy Bypass -File .\Build.ps1          # app + both installers
powershell -ExecutionPolicy Bypass -File .\Build.ps1 -NoSetup # app only
```

`Build.ps1` uses `%windir%\Microsoft.NET\Framework64\v4.0.30319\csc.exe` and references `System.Management.Automation.dll` from the GAC. The version is read from `$Version` in `Glance.ps1` and stamped into both executables and the installer.

## Run without building

```powershell
powershell -STA -ExecutionPolicy Bypass -File .\Glance.ps1
```

Script mode behaves identically to the exe; the only differences are the process name (`powershell.exe`) and the *About* page wording. The script relaunches itself under Windows PowerShell 5.1 / STA if started from `pwsh`.

## Test

There is a headless smoke test built into the app. It constructs the full UI, samples metrics for ~3.5 s, prints every rendered row and every settings page, and exits 0.

```powershell
$env:GLANCE_HEADLESS = '1'
$env:GLANCE_SHOT     = "$PWD\docs\screenshots"   # optional: also save PNG screenshots
$env:GLANCE_OUT      = "$env:TEMP\glance.txt"    # optional (exe only): copy of the output, since GUI exes can't be piped

# script mode
powershell -STA -ExecutionPolicy Bypass -File .\Glance.ps1

# exe mode (Start-Process is needed: PowerShell does not wait for GUI-subsystem executables)
$p = Start-Process .\dist\Glance.exe -PassThru; $p.WaitForExit(); $p.ExitCode
```

Installer round-trip:

```powershell
.\dist\Glance-Setup.exe /S            # install silently
& "$env:LOCALAPPDATA\Programs\Glance\Uninstall.cmd" /S
```

What the installer touches: `%LocalAppData%\Programs\Glance\`, `Glance.lnk` in the Start Menu and (optionally) the Startup folder, and `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\Glance`. Nothing system-wide.

## Architecture notes

- **Threads.** A worker runspace samples metrics and pushes hashtables into a synchronized `Queue`; a 250 ms `DispatcherTimer` on the UI thread drains it. The worker never touches UI objects, and no scriptblocks cross runspaces.
- **Metrics.** `Win32_PerfFormattedData_*` CIM classes (locale-independent, unlike `Get-Counter`), `NetworkInterface.GetIPStatistics()` deltas for network, `nvidia-smi --query-gpu` when present, otherwise `GPUPerformanceCounters_GPUEngine`. Top process is computed from `TotalProcessorTime` deltas every other tick.
- **Overlay window.** `WindowStyle=None`, `AllowsTransparency`, `Topmost`, plus `WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE` so it never takes focus or appears in Alt-Tab. Click-through toggles `WS_EX_TRANSPARENT`. Topmost is re-asserted every 3 s because some full-screen apps steal it.
- **Settings window.** `WindowChrome` with custom caption; all controls (switch, chip, slider, scrollbar) are restyled `CheckBox` / `RadioButton` / `Slider` templates — no third-party UI library.
- **Host.** `src\Host.cs` creates a runspace with `UseCurrentThread` on an `[STAThread]` `Main`, so `Application.Run` blocks the main thread as WPF expects. Script errors are logged to `%AppData%\Glance\error.log` and surfaced in a dialog.
- **Why not IExpress?** It was tried for the installer exe; Defender flags its output (`Program:Win32/Contebrew.A!ml`). A compiled stub has no such problem.

## Gotchas collected along the way

- PowerShell parameters are case-insensitive: a `$Tag` parameter and a `$tag` local are the same variable.
- `Write-Output` inside a `DispatcherTimer` tick never reaches the host pipeline — log to a file instead.
- `powershell -File` passes arguments literally; `-SetupArgs '/S'` keeps the quotes. The setup stub uses escaped double quotes.
- The uninstaller's own PowerShell command line contains `Glance`; filter `$PID` out before stopping processes, or it kills itself.
- `& .\Glance.exe` returns immediately and leaves `$LASTEXITCODE` stale (GUI subsystem). Use `Start-Process -PassThru` and `WaitForExit`.
